Guias de eventos JavaScript

Clique nas guias para estudar cada evento. Cada guia traz explicação, exemplo ao vivo e o código usado.

Guia 1 de 15

onclick

Ocorre quando o usuário clica e solta o botão do mouse sobre o elemento. É o evento mais usado em botões, links e ações simples.

Exemplo ao vivo

Cliques: 0

Código JavaScript onclick 
const botao = document.querySelector('#demo-click');
const retorno = document.querySelector('#retorno-click');
let cliques = 0;

botao.onclick = function () {
  cliques = cliques + 1;
  retorno.textContent = 'Cliques: ' + cliques;
};

ondblclick

Ocorre quando o usuário realiza dois cliques rápidos no mesmo elemento. Observe que os dois cliques simples também acontecem antes dele.

Exemplo ao vivo

Aguardando o duplo clique...

Código JavaScript ondblclick 
const area = document.querySelector('#demo-dblclick');
const retorno = document.querySelector('#retorno-dblclick');

area.ondblclick = function () {
  retorno.textContent = 'Duplo clique detectado!';
  area.textContent = 'Muito bem!';
};

onmouseover

Ocorre quando o ponteiro do mouse entra no elemento. É parecido com mouseenter, mas também dispara ao entrar em elementos filhos.

Exemplo ao vivo

🐱 Passe o mouse aqui

O mouse ainda não entrou.

Código JavaScript onmouseover 
const area = document.querySelector('#demo-mouseover');
const retorno = document.querySelector('#retorno-mouseover');

area.onmouseover = function () {
  retorno.textContent = 'O mouse entrou na área!';
  area.classList.add('bg-info-subtle');
};

onmouseout

Ocorre quando o ponteiro sai do elemento. É o oposto de onmouseover e costuma ser usado para voltar ao visual original.

Exemplo ao vivo

🐶 Entre e depois saia daqui

O mouse ainda não saiu.

Código JavaScript onmouseout 
const area = document.querySelector('#demo-mouseout');
const retorno = document.querySelector('#retorno-mouseout');

area.onmouseout = function () {
  retorno.textContent = 'O mouse saiu da área!';
  area.classList.remove('bg-info-subtle');
};

onmousemove

Ocorre várias vezes enquanto o ponteiro se move dentro do elemento. É útil para mostrar coordenadas, arrastar objetos ou criar efeitos que acompanham o mouse.

Exemplo ao vivo

Mova o mouse por aqui

Posição: aguardando movimento...

Código JavaScript onmousemove 
const area = document.querySelector('#demo-mousemove');
const retorno = document.querySelector('#retorno-mousemove');

area.onmousemove = function (evento) {
  retorno.textContent = 'X: ' + evento.offsetX + ' | Y: ' + evento.offsetY;
};

onmousedown

Ocorre no momento em que um botão do mouse é pressionado sobre o elemento, antes de ser solto. O valor 0 representa o botão esquerdo.

Exemplo ao vivo

Botão ainda não pressionado.

Código JavaScript onmousedown 
const botao = document.querySelector('#demo-mousedown');
const retorno = document.querySelector('#retorno-mousedown');

botao.onmousedown = function (evento) {
  retorno.textContent = 'Botão ' + evento.button + ' pressionado!';
};

onmouseup

Ocorre quando o botão do mouse é solto sobre o elemento. Normalmente acontece depois de onmousedown e antes de onclick.

Exemplo ao vivo

Botão ainda não solto.

Código JavaScript onmouseup 
const botao = document.querySelector('#demo-mouseup');
const retorno = document.querySelector('#retorno-mouseup');

botao.onmouseup = function () {
  retorno.textContent = 'Botão solto!';
};

onfocus

Ocorre quando o elemento recebe o foco, seja por clique ou pela tecla Tab. É muito usado em campos de formulário para mostrar dicas.

Exemplo ao vivo

O campo ainda não está em foco.

Código JavaScript onfocus 
const campo = document.querySelector('#demo-focus');
const retorno = document.querySelector('#retorno-focus');

campo.onfocus = function () {
  retorno.textContent = 'O campo recebeu o foco!';
};

onchange

Ocorre quando o valor de um campo é alterado. Em uma lista select, dispara ao escolher uma opção; em campos de texto, dispara quando o valor muda e o campo perde o foco.

Exemplo ao vivo

Nenhuma opção escolhida.

Código JavaScript onchange 
const select = document.querySelector('#demo-change');
const retorno = document.querySelector('#retorno-change');

select.onchange = function (evento) {
  const escolha = evento.target.value;
  retorno.textContent = escolha === ''
    ? 'Nenhuma opção escolhida.'
    : 'Você escolheu: ' + escolha;
};

onblur

Ocorre quando o elemento perde o foco. É o oposto de onfocus e é ideal para validar um campo depois que a pessoa termina de digitar.

Exemplo ao vivo

O campo ainda não perdeu o foco.

Código JavaScript onblur 
const campo = document.querySelector('#demo-blur');
const retorno = document.querySelector('#retorno-blur');

campo.onblur = function () {
  const texto = campo.value.trim();
  retorno.textContent = texto === ''
    ? 'O campo ficou vazio.'
    : 'Você digitou: ' + texto;
};

onkeydown

Ocorre quando uma tecla é pressionada. Se a tecla ficar segurada, o evento se repete. É indicado para atalhos, setas e teclas de controle.

Exemplo ao vivo

Nenhuma tecla pressionada.

Código JavaScript onkeydown 
const campo = document.querySelector('#demo-keydown');
const retorno = document.querySelector('#retorno-keydown');

campo.onkeydown = function (evento) {
  retorno.textContent = 'Tecla: ' + evento.key +
    ' | Código: ' + evento.code;
};

onkeypress

Ocorria quando uma tecla que gera caractere era pressionada. Este evento está obsoleto; em código novo, use onkeydown ou beforeinput.

Exemplo ao vivo

Nenhum caractere digitado.

Código JavaScript onkeypress 
const campo = document.querySelector('#demo-keypress');
const retorno = document.querySelector('#retorno-keypress');

campo.onkeypress = function (evento) {
  retorno.textContent = 'Caractere: ' + evento.key;
};

onkeyup

Ocorre quando uma tecla é solta. É muito usado para contar caracteres ou atualizar a tela depois que a digitação termina.

Exemplo ao vivo

Nenhuma tecla solta.

Código JavaScript onkeyup 
const campo = document.querySelector('#demo-keyup');
const retorno = document.querySelector('#retorno-keyup');

campo.onkeyup = function (evento) {
  retorno.textContent = 'Você soltou a tecla: ' + evento.key;
};

onload

Ocorre quando a página, uma imagem ou outro recurso termina de carregar. Em window, é usado para iniciar ações assim que tudo estiver pronto.

Exemplo ao vivo

Aguardando o carregamento...

Código JavaScript onload 
window.onload = function () {
  const agora = new Date().toLocaleTimeString('pt-BR');
  const retorno = document.querySelector('#retorno-load');
  retorno.textContent = 'Página carregada às ' + agora + '.';
};

onresize

Ocorre quando o tamanho da janela do navegador é alterado. Redimensione a janela para ver as medidas sendo atualizadas.

Exemplo ao vivo

Medidas: aguardando...

Código JavaScript onresize 
const retorno = document.querySelector('#retorno-resize');
let atualizacoes = 0;

function mostrarMedidas() {
  atualizacoes = atualizacoes + 1;
  retorno.textContent = 'Janela: ' + window.innerWidth +
    ' x ' + window.innerHeight + ' px | Atualizações: ' + atualizacoes;
}

window.onresize = mostrarMedidas;
mostrarMedidas();
